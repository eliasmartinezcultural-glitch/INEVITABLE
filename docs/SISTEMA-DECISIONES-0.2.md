# INEVITABLE — SISTEMA DE DECISIONES Y CONSECUENCIAS 0.2

## Principio
Una decisión no debe ser una pantalla de elección. Debe modificar variables, territorio, memoria y problemas futuros.

## Cadena sistémica
DECISIÓN → COSTO → OBRA/COMPORTAMIENTO → CAMBIO VISIBLE → NUEVA PRESIÓN → MEMORIA → CONSECUENCIA POSTERIOR.

## Tipos de decisión
- Territorio: dónde producir, concentrar población, conectar o reservar.
- Agua: trazado, capacidad, cobertura, mantenimiento y prioridades.
- Producción: preparar tierra, activar producción, almacenar, transportar o conservar margen.
- Población: atraer trabajadores, construir hogares, concentrar o dispersar asentamiento.
- Infraestructura: canales, caminos, servicios y futuras redes.
- Comunidad: confianza, acceso, promesas, prioridades y tensiones entre crecimiento y estabilidad.

## Tipos de consecuencia
- inmediata;
- territorial;
- económica;
- social;
- hídrica;
- productiva;
- temporal;
- histórica.

## Incertidumbre
El juego no debe fingir que el jugador conoce el futuro.

Una decisión puede mostrar:
- efecto conocido;
- costo conocido;
- riesgo probable;
- consecuencia incierta.

Nunca usar “+10 puntos” como sustituto de una consecuencia narrativa.

## Memoria
Cada decisión significativa se guarda como una frase comprensible.

Ejemplo:
“1968: se priorizó el agua antes que la expansión.”

Décadas después, el motor puede consultar esa memoria para generar mayor capacidad, mayor mantenimiento, expansión favorecida, presión habitacional o ventajas/desventajas logísticas.

## Territorio
La representación visual es obligatoria:
- un canal aparece;
- un camino aparece;
- una casa aparece;
- una zona cambia de uso;
- una ruta de circulación se consolida;
- una parcela puede activarse;
- una presión puede mostrarse.

## Interfaz multidispositivo
### Escritorio
Mapa dominante + panel lateral.

### Tablet
Mapa dominante + panel adaptable.

### Teléfono
Mapa a pantalla completa + panel inferior tipo hoja. Las decisiones nunca deben sacar al jugador del mapa.

### Accesibilidad
- controles táctiles grandes;
- contraste;
- teclado 1–4 para herramientas;
- respeto por prefers-reduced-motion;
- textos cortos;
- no depender solo de color.

## Guardado
localStorage almacena estado, decisiones, memoria, eventos, obras y progreso temporal. No necesita servidor.
