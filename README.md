# INEVITABLE

**San Patricio del Chañar — Construí la historia**

Núcleo inicial de una experiencia histórica interactiva para GitHub Pages.

## Leyes mundiales
- Historia documentada separada de hipótesis.
- Decisiones con consecuencias.
- Agua, territorio y comunidad como sistemas conectados.
- Sin backend: estado local.
- Mobile-first y multidispositivo.
- Arquitectura ampliable.

## Fuente histórica inicial
El núcleo cronológico utiliza documentación oficial y territorial disponible en Argentina.gob.ar y la Carta Orgánica Municipal. La fecha oficial de fundación reconocida es el 21 de mayo de 1973.
