# INEVITABLE — San Patricio del Chañar

**Construí la historia.**

INEVITABLE es un juego web histórico-territorial sobre la transformación de San Patricio del Chañar. El jugador administra territorio, agua, producción, vivienda, infraestructura y comunidad dentro de una línea temporal anclada en hechos documentados.

## Principio central

> **La historia documentada no se modifica. La partida construye una línea hipotética alrededor de ella.**

El juego diferencia internamente tres estados:

- **HISTÓRICO** — respaldado por documentación.
- **SIMULADO** — comportamiento del sistema del juego.
- **HIPOTÉTICO** — alternativa creada por las decisiones del jugador.

## Arquitectura objetivo

Proyecto estático para GitHub Pages:

- HTML
- CSS
- JavaScript modular
- SVG para el territorio interactivo
- localStorage para partidas
- sin backend
- sin base de datos
- sin servicios pagos

## Regla de diseño

El mapa es la experiencia principal. Los números explican el mundo; no lo reemplazan.
